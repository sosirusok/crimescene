# Crime Scene Play

부산 서면 크라임씬플레이의 고객 예약 사이트와 보안 운영 콘솔입니다. 단일 랜딩 페이지가 아니라 사건 소개, 사건 상세, 실시간 예약, 예약 정보 입력, 완료, 조회, 취소, 공지, FAQ·1:1 문의, 이용 안내, 오시는 길, 약관 페이지로 구성되어 있습니다.

## 핵심 기능

- 4개 사건별 실제 회차 시간표와 15일 실시간 예약 현황
- 좌석 동시성 제어, 오픈룸 합류, 고객에게 노출되지 않는 내부 식별값
- 이름·휴대폰 번호 기반 예약 조회와 시작 24시간 전 온라인 취소
- 공지와 고객 문의 데이터베이스 저장
- ChatGPT 로그인 + `ADMIN_EMAILS` 허용 목록으로 보호되는 `/admin`
- 예약·결제 상태, 오늘 일정, 문의, 회차 차단, 공지 등록 운영 기능
- KISPG 가맹점 연결을 위한 결제 상태 모델과 안전한 연결 지점
- 휴대폰 조회 해시·마스킹, 선택적 AES-GCM 연락처 암호화, 감사 로그

## 실행 및 검증

```bash
npm install
npm run db:generate
npm run dev
npm run lint
npm run build
```

필요한 환경변수는 `.env.example`, KISPG 연결 절차는 `docs/KISPG_SETUP.md`를 확인하세요. KISPG 비밀값과 개인정보 암호화 키는 저장소에 커밋하지 않습니다.
